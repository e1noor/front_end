02 - SYNTAX

How a CSS rule is written

Selector: chooses the HTML element.

Property: says what will change.

Value: says how it will look.

03 - SELECTORS

Four selector types

p

Element

Styles every tag of the same type.

p { color: #222; }
.card

Class

Can be reused on many elements.

.card { padding: 20px; }
#header

ID

Targets one unique element.

#header { color: white; }
nav a

Descendant

Targets an element inside another.

nav a { padding: 10px; }

05 - BOX MODEL

Every element is a box

The browser calculates the size of each element using four layers. Reading them from the inside out makes the box model easier to remember.

  1. Content - the text or image.
  2. Padding - space inside the border.
  3. Border - the line around the element.
  4. Margin - space outside the border.
