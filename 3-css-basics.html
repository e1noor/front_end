The box model

The browser calculates every element as four layers. Reading from the inside out makes the order easier to remember.

  1. Content - text or an image.
  2. Padding - space inside the border.
  3. Border - the line around an element.
  4. Margin - space outside the border.

Rule structure

A CSS rule has a selector and a declaration block. Each declaration contains a property and a value.

.notice {
    color: navy;
    background-color: lightblue;
}

Good color contrast

Dark text on a light background is easy to read. The same rule should be followed for buttons, links, and navigation.
