    Flexbox example

    Flexbox is useful for navigation, button groups, and small groups of items.

    .container {
    display: flex;
    justify-content: space-between;
    align-items: center;
}

    Grid example

    Grid is useful for galleries, dashboards, and larger page sections.

    .container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 16px;
}

    Responsive design

    A media query applies styles only when a screen matches a condition. This project uses mobile styles first, then tablet and desktop breakpoints.

    • Mobile: content is stacked.
    • Tablet: two cards fit in a row.
    • Desktop: three cards fit in a row.
    Review CSS Basics 
    @media (min-width: 768px) {
    .cards { grid-template-columns: repeat(2, 1fr); }
}

@media (min-width: 992px) {
    .cards { grid-template-columns: repeat(3, 1fr); }
}
