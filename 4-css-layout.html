CSS Layout

CSS layout controls the size and position of elements. A good layout creates clear groups and adapts to mobile, tablet, and desktop screens.

Prepared by Yelnur Yessenali - SE-2514

Basics Layout

Three layout tools

Choose a tool based on whether the content needs one direction, two directions, or screen-specific changes.

Flexbox

Flexbox arranges items in one direction: a row or a column.

Grid

Grid arranges items in rows and columns at the same time.

Spacing

Consistent gaps make sections easier to scan and understand.

Flexbox example

Flexbox is useful for navigation, button groups, and small groups of items.

.container {
    display: flex;
    justify-content: space-between;
    align-items: center;
}

Grid example

Grid is useful for galleries, dashboards, and larger page sections.

.container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 16px;
}

Responsive design

A media query applies styles only when a screen matches a condition. This project uses mobile styles first, then tablet and desktop breakpoints.

  • Mobile: content is stacked.
  • Tablet: two cards fit in a row.
  • Desktop: three cards fit in a row.
Review CSS Basics 
@media (min-width: 768px) {
    .cards { grid-template-columns: repeat(2, 1fr); }
}

@media (min-width: 992px) {
    .cards { grid-template-columns: repeat(3, 1fr); }
}
