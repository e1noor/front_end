01 - LAYOUT

CSS Layout

CSS layout controls the size and position of elements. A good layout creates clear groups, keeps enough space between them, and adapts to different screen sizes.

02 - NORMAL FLOW

The browser's default layout

Block elements normally take the available width and appear from top to bottom. Inline elements stay in the same line until there is no more space.

03 - FLEXBOX

One direction at a time

Flexbox places items in a row or a column. It is useful for navigation, buttons, and groups of cards.

  • display: flex starts a flex layout.
  • justify-content controls main-axis spacing.
  • align-items controls cross-axis alignment.
  • gap adds space between items.

display: flex; justify-content: space-between;

04 - GRID

Rows and columns together

Grid creates a two-dimensional layout. It is a good choice for galleries, dashboards, and page sections that must line up in both directions.

  1. Choose the number of columns.
  2. Add a gap between cells.
  3. Place wider items across several columns.
