03 - VARIABLES

Declaring a variable

In JavaScript there are three ways to declare a variable:

  • let a variable whose value can be changed
  • const a constant, its value cannot be changed
  • var an outdated way, rarely used

04 - DATA TYPES

Data Types

  • Number numbers (e.g. 10, 3.14)
  • String text strings (e.g. "Hello")
  • Boolean true or false
  • Array a collection of values
  • Object an object with keys and values

05 - CONDITIONS & LOOPS

Conditions and Loops

The if / else construction allows code to run only when certain conditions are met. Loops such as for and while are used to repeat actions multiple times.

06 - FUNCTIONS

Functions

A function is a block of code that can be called multiple times, so you don't have to duplicate the same actions in different parts of the program.
