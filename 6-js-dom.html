What is the DOM

DOM (Document Object Model) is a representation of an HTML page as a tree of objects that JavaScript can work with. Each tag becomes a node of the tree, accessible for reading and modification through code.

Why the DOM is Needed

Thanks to the DOM, JavaScript can change text, styles, add or remove elements on a page without reloading it this is the foundation of interactive websites.

Main Methods

  • getElementById() - finds an element by its id
  • querySelector() - finds an element by a CSS selector
  • addEventListener() - adds an event handler (click, input, etc.)
  • innerHTML - changes the content of an element
