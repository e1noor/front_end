Working with the DOM

DOM (Document Object Model) represents an HTML page as a tree of objects. JavaScript can find and change these objects.

Why the DOM is needed

JavaScript uses the DOM to change text and styles, add or remove elements, and respond to clicks without reloading the page.

DOM questions

Click a question to show or hide its answer.

The DOM is a tree of objects that represents an HTML page. JavaScript can use it to change text, styles and elements.

Use document.getElementById("example") to find the element with id="example". Then you can change its textContent or style.

An event listener waits for an action, such as a click. The addEventListener method tells JavaScript which function to run when that action happens.
